Private backup utility

RTP Backup

RTP Backup copies encrypted server backup repositories to a Google Drive folder selected by the backup administrator. It uses rclone and the Google Drive API for offsite backup storage.

This is an information page for a privately operated backup tool. It does not provide public registration, collect credentials, or grant access to backups.

How the tool is used

  • The administrator authorizes access to the Google account used for backup storage.
  • The uploader reads local encrypted backup objects and adds missing objects to the configured Drive backup folder.
  • The current uploader preserves existing destination objects; deletion or retention changes require a separate administrator action.
  • Transfer logs and status checks help the administrator identify incomplete or failed uploads.

Google Drive access

The tool requests the Google Drive access scope needed to locate and maintain the existing backup folder. This OAuth permission is broader than the folder used by the configured upload job. Authorization is completed on Google's consent screen; this website has no sign-in form.

Privacy and contact

Read the RTP Backup Privacy Notice for the information accessed, how it is used, and how to revoke access or request removal. For questions, contact the backup administrator using the User support email displayed for RTP Backup on the Google authorization screen.
